# Launch checklist — first digital product sale

- [ ] Final file exports cleanly (Sheet/PDF) on a fresh account
- [ ] Cover image 1:1 and 16:9 variants
- [ ] Listing title + tags drafted (`python3 listing.py ...`)
- [ ] Price set; test purchase on Gumroad or Etsy
- [ ] Thank-you / delivery note includes how to open the file
- [ ] One distribution push: relevant subreddit, Indie Hackers, or niche Discord (no spam)
- [ ] Track first 10 visitors → purchase in a simple sheet
